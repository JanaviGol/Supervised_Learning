Logistic Regression — Ek Line Mein
Logistic Regression = ek classification algorithm jo input features se probability predict karta hai ki sample class 1 se belong karta hai.

"Logistic" naam se "regression" lagta hai — lekin ye classification karta hai! Output: P(y=1|X) = 0 se 1 ke beech — ek probability.
❌ Linear Regression for Classification — 3 Problems!
❌ Problem 1: Output >1 ya <0 possible — probability nahi ho sakta!
❌ Problem 2: Decision boundary arbitrary hoti hai.
❌ Problem 3: Outliers line ko bahut affect karte hain.
SIGMOID FUNCTION
σ(z) = 1 / (1 + e⁻ᶻ)
z = w₀ + w₁x₁ + … = linear combination of inputs (any value −∞ to +∞)
σ(z) ∈ (0,1) hamesha!  |  σ(0)=0.5  |  z→+∞: σ→1  |  z→−∞: σ→0
✅ Sigmoid Curve — Hamesha (0, 1) ke Beech!
🔢
z = Linear Combination
z = w₀ + w₁×hours + w₂×attendance — ek normal linear output. Koi bhi value −∞ se +∞ tak ho sakta hai.
🌊
σ(z) = Probability
Sigmoid z ko (0,1) mein squeeze karta hai. σ(z) = P(y=1|X). Large positive z → high probability of class 1!
✂️
Threshold = 0.5
σ(z) ≥ 0.5 → Class 1. σ(z) < 0.5 → Class 0. Decision boundary at z=0 yaani w₀+w₁x₁+…=0.
🇮🇳 India Real-World Use Cases
🎓 Exam Pass/Fail: Study hours, attendance → Pass (1) ya Fail (0)?
💳 Loan Approved?: Income, credit score → Approve (1) ya Reject (0)?
🦠 Disease Detection: Age, BP, BMI → Diabetes (1) ya Healthy (0)?
🔒 Fraud Detection: Transaction amount, location → Fraud (1) ya Legit (0)?
📧 Spam Filter: Email features → Spam (1) ya Not Spam (0)?
🎯 Ad Click: User profile → Click (1) ya No Click (0)?
🤔 Ek student ka z = −2.0 calculate hua. Sigmoid σ(−2) kya hoga? Model student ko pass predict karega? (e² ≈ 7.39)
Aσ(−2) = 0.88 — high probability, pass predict karega
Bσ(−2) = 0.5 — exactly at decision boundary
Cσ(−2) ≈ 0.119 — Fail predict karega (probability < 0.5)
Dσ(−2) = 0 — exactly zero probability

Mathematical Formulation — Log-Odds, Loss aur Gradient Descent!
+30 XP on scroll
The Big Picture — Logistic Regression kaise seekhta hai?
LR do cheezein seekhta hai: weights (w₀, w₁, …, wₙ).
Training mein: aise weights dhundho ki predicted probabilities actual labels ke saath maximum match karein.
Math: Cross-Entropy Loss minimize karo using Gradient Descent!
LOGISTIC REGRESSION MODEL
ŷ = P(y=1|X) = σ(w₀ + w₁x₁ + … + wₙxₙ) = 1/(1+e^−(Xw))
w = weight vector  |  Decision: predict 1 if ŷ ≥ 0.5, else 0
Log-Odds (logit) = log[ŷ/(1−ŷ)] = z = Xw — linear relationship with features!
MSE for Classification — Kyun Nahi?
Linear Regression mein MSE = (y−ŷ)² use karte hain. Classification mein kyun nahi?
→ Non-convex loss → multiple local minima → gradient descent stuck!
→ Solution: Cross-Entropy Loss — convex, fast convergence, probabilistically motivated!
BINARY CROSS-ENTROPY LOSS (1 sample)
L(y, ŷ) = −[y·log(ŷ) + (1−y)·log(1−ŷ)]
y=1: L = −log(ŷ) → ŷ=1 pe loss=0 ✅   ŷ→0 pe loss→∞ ❌ (penalize heavily!)
y=0: L = −log(1−ŷ) → ŷ=0 pe loss=0 ✅   ŷ→1 pe loss→∞ ❌
TOTAL LOSS — OVER ALL N SAMPLES
J(w) = −(1/N) Σᵢ [yᵢ·log(ŷᵢ) + (1−yᵢ)·log(1−ŷᵢ)]
Average loss. This is what gradient descent minimizes! Also called "Log Loss".
GRADIENT DESCENT UPDATE
wⱼ ← wⱼ − α × (1/N) Σᵢ (ŷᵢ − yᵢ) × xᵢⱼ    (in matrix form: w ← w − α × Xᵀ(ŷ−y)/N)
α = learning rate  |  (ŷ−y) = residual = prediction error
Beautiful! Same form as Linear Regression gradient — but ŷ comes from sigmoid!
σ(z)Sigmoid — maps z to (0,1)
J(w)Cross-entropy loss to minimize
ŷ−yResidual / prediction error
αLearning rate — step size
epochOne full pass through training data
C=1/λRegularization — prevents overfitting
🤔 Actual y=1, Predicted ŷ=0.90. Cross-entropy loss kya hoga? (ln(0.9) ≈ −0.105)
A0.01 — (y−ŷ)² = (1−0.9)² = 0.01 (MSE)
B≈ 0.105 — −log(0.90) = 0.105 (correctly penalizes wrong confidence)
C2.30 — large loss kyunki model far from correct
D−0.105 — negative loss because model correct hai

🐍 python — logistic regression from scratch 
import numpy as np

class LogisticRegressionScratch:
    """Binary Logistic Regression via Gradient Descent — fully commented."""
    def __init__(self, lr=0.1, epochs=1000, lambda_=0.01):
        self.lr = lr
        self.epochs = epochs
        self.lambda_ = lambda_    # L2 regularization
        self.w = None
        self.b = None
        self.loss_hist = []

    def _sigmoid(self, z):
        z = np.clip(z, -500, 500)
        return 1.0 / (1.0 + np.exp(-z))

    def fit(self, X, y):
        N, n = X.shape
        self.w = np.zeros(n)
        self.b = 0.0

        for ep in range(self.epochs):
            # Forward: linear → sigmoid
            z     = X @ self.w + self.b
            y_hat = self._sigmoid(z)

            # Gradients (same elegant form as Linear Regression!)
            err = y_hat - y
            dw  = (X.T @ err) / N + (self.lambda_ / N) * self.w
            db  = err.mean()

            # Update weights
            self.w -= self.lr * dw
            self.b -= self.lr * db

            if ep % 100 == 0:
                loss = -np.mean(y*np.log(y_hat+1e-15) + (1-y)*np.log(1-y_hat+1e-15))
                self.loss_hist.append(round(loss, 4))
        return self

    def predict_proba(self, X):
        return self._sigmoid(X @ self.w + self.b)

    def predict(self, X, thresh=0.5):
        return (self.predict_proba(X) >= thresh).astype(int)

    def score(self, X, y):
        return (self.predict(X) == y).mean()


# ── Simple Example: Study Hours → Pass/Fail ───────────────────

🐍 python — sklearn full pipeline (loan default prediction) 
import numpy as np
import pandas as pd
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.metrics import (classification_report, roc_auc_score,
                              accuracy_score, confusion_matrix)

np.random.seed(42)

# ── 🇮🇳 HDFC Bank: Loan Default Dataset ──────────────────────
n = 1000
df = pd.DataFrame({
    'Annual_Income': np.random.normal(600000, 150000, n).clip(200000, 1500000),
    'Credit_Score':  np.random.normal(720, 80, n).clip(500, 900).astype(int),
    'Loan_Amount':   np.random.normal(500000, 200000, n).clip(100000, 2000000),
    'Employ_Years':  np.random.randint(1, 20, n),
    'EMI_ratio':     np.random.uniform(0.1, 0.6, n),
})

# Realistic default probability
logit = (0.000002*df.Annual_Income + 0.02*df.Credit_Score
         + 0.2*df.Employ_Years - 5*df.EMI_ratio - 18)
df['Default'] = (np.random.rand(n) < 1/(1+np.exp(-logit)) * 0.12).astype(int)
print(f"Default rate: {df.Default.mean()*100:.1f}%")

feats = ['Annual_Income','Credit_Score','Loan_Amount','Employ_Years','EMI_ratio']
X, y = df[feats].values, df.Default.values

X_tr, X_te, y_tr, y_te = train_test_split(
    X, y, test_size=.2, stratify=y, random_state=42)

# ── Pipeline: Scale + Logistic Regression ────────────────────
pipe = Pipeline([
    ('sc', StandardScaler()),
    ('lr', LogisticRegression(C=1.0, penalty='l2',
                               class_weight='balanced',
                               solver='lbfgs', max_iter=1000,
                               random_state=42))
])
pipe.fit(X_tr, y_tr)

y_pred = pipe.predict(X_te)
y_prob = pipe.predict_proba(X_te)[:,1]

print("\n📊 Results:")
print(f"  Accuracy  : {accuracy_score(y_te, y_pred)*100:.2f}%")
print(f"  ROC-AUC   : {roc_auc_score(y_te, y_prob):.4f}")
print(classification_report(y_te, y_pred, target_names=['No Default','Default']))

# ── 5-Fold CV ────────────────────────────────────────────────
cv = cross_val_score(pipe, X, y, cv=5, scoring='roc_auc')
print(f"5-Fold CV AUC: {cv.mean():.4f} ± {cv.std():.4f}")

# ── Feature Importance (Coefficients) ────────────────────────
coef = pipe.named_steps['lr'].coef_[0]
print("\n📊 Feature Coefficients (standardized):")
for nm, c in sorted(zip(feats, coef), key=lambda x: abs(x[1]), reverse=True):
    print(f"  {nm:20}: {c:+.3f}  ({'⬆️ Default' if c>0 else '⬇️ Default'})")

# ── Predict for new customer ──────────────────────────────────
cust = pd.DataFrame([[450000,680,800000,3,0.45]], columns=feats)
prob = pipe.predict_proba(cust)[0,1]
pred = pipe.predict(cust)[0]
print(f"\n🏦 Customer (4.5L income, score=680, 8L loan, 3yr exp, EMI=45%):")
print(f"  P(Default)={prob:.3f} → {'⚠️ REJECT' if pred else '✅ APPROVE'}")
